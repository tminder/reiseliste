| F-003 | Geschäftsmodell: kostenlos, Reise-Pass als Einmalkauf (3–5 € pro Reise) oder Abo? | Seltene, saisonale Nutzung spricht eher gegen ein Abo. Bei einem bezahlten Angebot braucht es ein anderes Hosting, weil GitHub Pages keine kommerziellen Dienste erlaubt. Vorgemerkt ist **Bunny.net** (Slowenien, EU-Recht, weltweites Servernetz, ab etwa 1 $ pro Monat, Upload per GitHub Actions). Alternativen: Hostfactory (Schweiz, ab CHF 9.90, Paket mit SSH) oder Cloudflare Pages (gratis, US-Firma). Ebenfalls vor einem kommerziellen Betrieb: die öffentlichen OpenStreetMap-Dienste (Nominatim, Overpass) ersetzen, Impressum und Datenschutzerklärung anpassen. |
